Como Executar a Aplicação

    Estrutura de Pastas: Certifique-se de que os quatro arquivos (.env, requirements.txt, db_utils.py, streamlit_app.py) estejam na mesma pasta.

    Instale as Dependências: Abra seu terminal, navegue até a pasta do projeto e execute:
    Bash

        pip install -r requirements.txt

    Execute o Streamlit: No mesmo terminal, execute o comando:
    
    Bash

        streamlit run streamlit_app.py

Sua aplicação será aberta em uma nova aba do navegador, pronta para ser usada, seguindo exatamente o fluxo descrito no prompt.
